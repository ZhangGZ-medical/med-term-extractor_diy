# 核心算法：拉丁簇状态机中英切分

## 问题定义

名词类书籍的词条行结构为「中文正名 + 英文名」，但中文正名内常嵌拉丁字符：

| 词条 | 内嵌拉丁 | 英文名 |
|---|---|---|
| ABO 血型鉴定（反定型） | ABO | determining ABO blood group of serum |
| 亚甲基四氢叶酸还原酶基因 677C/T检测 | 677C/T | methylenetetrahydrofolate reductase gene 677C/T detection |
| 蛋白C | C | protein C |
| D- 二聚体 | D- | D-dimer |
| Th1、Th2 细胞计数 | Th1、Th2 | Th1,Th2 count |
| α2-抗纤溶酶 | α2- | α2-antiplasmin |

若简单地"遇拉丁即切"，会把 ABO/677C/T/蛋白C 里的拉丁误判为英文起点。

## 状态机规则

定义**拉丁簇**：连续 `[A-Za-zαβΑΒ0-9\-/]*` 段（正则 `[A-Za-zαβΑΒ][A-Za-zαβΑΒ0-9\-/]*`）。

逐簇扫描，维护状态（cn=中文段 / en=英文段）：

1. **cn 态，簇后跟中文**（穿透 `空格 - – / （ ） 、 ， · : ； 。 0-9` 后看首个有效字符）→ 中文内嵌拉丁，跳过，保持 cn 态。
   - "ABO 血型鉴定" → ABO 簇后是"血"→ 跳过
   - "677C/T检测" → 677C/T 簇后是"检"→ 跳过
   - "α 2- 抗纤溶酶" → α 簇后穿透" 2- "是"抗"→ 跳过
2. **cn 态，簇是单个大写字母且后跟空格+小写词** → 中文词条尾部字母，跳过。
   - "蛋白C protein C" → C 后跟" protein"→ 跳过（起点落在 protein）
3. **cn 态，其他情况**（簇后跟拉丁/行尾）→ **英文起点**，记入 starts，进入 en 态。
4. **en 态，簇前 3 字符内出现中文** → 回 cn 态（该簇按规则 1-3 重新判定）；否则保持 en 态继续。
   - "determining ABO blood group of red cell ABO 血型系统抗体致新生儿溶血病检测 detection of ..."
     → determining 是起点1；英文段内 ABO/blood/... 保持 en；"血型系统..."是中文 → 回 cn；
       ABO（中文2内嵌）跳过；detection 是起点2 ✓

## 混行拆分（split_multi）

starts ≥ 2 且第 1、2 起点之间含中文 → 第 2 起点属于第 2 个词条，递归拆分。
注意：**不能**以"第 2 起点之前含中文"为条件——"a ngiotensin"（OCR 拆开的英文首字母）
中 a 和 ngiotensin 都会成为候选起点，但它们之间无中文，属同一英文。

## 无法自动解决的（必须人工修正）

1. **中文在前、英文在后的错序混行**：
   "IgM 血型抗 B 抗体效价测定 IgM血型抗A抗体效价测定 testing ... anti-A testing ... anti-B"
   两个中文都在前、两个英文都在后且顺序颠倒 → 状态机拆不开 → 医学知识判定对应关系。
2. **OCR 字符噪声**：Ⅸ→"区"、1→l、Ⅺa→"哑"、又称被拆两行（"［ 又"+"称J3P试验"）。
3. **跨栏英文续行**：左栏中文 + 英文前半，右栏页眉处孤立的英文后半（Becker muscular dystrophy 案例）。

## 调参经验

| 参数 | 默认 | 说明 |
|---|---|---|
| y_tol | 40 | 行聚类容差。<30 会把 OCR 拆开的英文首字母拆行；>50 会把相邻词条行合并 |
| split_x | 1050 | 双栏中缝。图宽 2292（300DPI A4）；可用 `--img-w` 适配其他尺寸 |
| 首字母拼接 | `^([a-zA-Z])\s+(?=[a-z])` | OCR 常把英文首字母单独成框（"a"+"ngiotensin"） |
| 断词合并 | `(\w+)-\s+(\w+)` | 行尾连字符断词（"qualita- tive"） |
